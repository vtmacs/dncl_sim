DNCL シミュレーター マニュアル

大学入試で使われる手順記述言語 DNCL / DNCL2 のプログラムを、ブラウザ上で実行・ステップ実行できるシミュレーターの説明書です。

1. はじめに

大学入試センターの試験では、特定のプログラミング言語に依存しない日本語の疑似言語でプログラムが書かれます。このシミュレーターは次の 2 つの書き方に対応しています。

名前使われた試験見た目の特徴
DNCL2大学入学共通テスト「情報Ⅰ」（令和 7 年度〜）、およびその試作問題x = 3、表示する(x)、もし … ならば:、字下げと縦線 │ ⎿ でブロックを表す。Python に近い。
DNCL大学入試センター試験・共通テスト「情報関係基礎」x ← 3、x を表示する、を実行する・を繰り返す でブロックを閉じる。

画面上部の「言語」で切り替えます。どちらの言語で書いたプログラムも、言語ごとに別々にブラウザへ自動保存されます。

もとにした資料（いずれも大学入試センター公表）
  • DNCL2：「令和７年度大学入学共通テスト 試作問題『情報』の概要」の「５．共通テスト用プログラム表記の例示」
  • DNCL：「共通テスト手順記述標準言語(DNCL)の説明」（2022 年 1 月）
仕様についての注意
「DNCL2」は「共通テスト用プログラム表記」の通称です。この表記は例示の形で公開されているだけで、細かい文法の定義はありません。このシミュレーターでは、例示から読み取れない部分を DNCL の説明資料や Python に近い動きで補っています（8. 細かい動作の決まり）。また、どちらの資料にも「問題文の記述を簡潔にするなどの理由で、この説明文書の記述内容に従わない形式で出題することもある」とあります。実際の問題では、問題文の説明が優先されます。

3. DNCL2（共通テスト「情報Ⅰ」用プログラム表記）

変数・配列・文字列

  • 変数名は英字で始まる英字・数字・_ の並びです。例：kosu、kosu_gokei、x1。大文字と小文字は区別されます。
  • 配列名は先頭を大文字にする決まりです。例：Tokuten、Data。（シミュレーターは小文字で始まる配列名も受け付けます。）
  • 配列の要素は Tokuten[2] のように添字で指定します。添字は 0 から始まります。
  • 二次元配列の要素は Gakuseki[1, 3] と書きます。Gakuseki[1][3] と書いても同じです。
  • 文字列は " で囲みます。例："情報"。「情報」 のようにかぎ括弧で囲んでも構いません。
  • 数値は整数と小数を扱えます。

代入文

kosu = 3
kosu_gokei = kosu * 2
Tokuten = [87, 45, 72, 100]
Tokuten[1] = 50
x = 1, y = 2, z = x + y
表示する(kosu_gokei, " ", Tokuten, " ", z)
  • = の右辺の値を左辺の変数（配列の要素）に代入します。
  • , で区切ると 1 行に複数の代入文を書けます。左から順に実行されます。
  • 配列全体には [ ] で値を並べて代入します。{ } でも構いません。
  • nyuryoku = 【外部からの入力】 で外部から入力された値を代入します（「入力」欄から読み込みます）。

次の書き方もできます。

Tokuten のすべての値を 0 にする
kosu = 5
kosu を 1 増やす
kosu を 2 減らす
Tokuten[3] を 10 増やす
表示する(kosu, " ", Tokuten[3], " ", Tokuten[99])

Tokuten のすべての値を 0 にする で配列のすべての要素を 0 にします（DNCL の書き方の Tokuten のすべての要素に 0 を代入する も使えます）。この文を使うと、それまで値を入れていない要素も 0 として読めるようになります（配列の大きさを決めずに数え上げなどに使えます）。

4. DNCL（旧センター試験「情報関係基礎」）

DNCL は、ブロックを「終わりの言葉」で閉じる書き方です。字下げや縦線 ｜ は読みやすくするためのもので、意味は持ちません（説明資料にも「改行位置によって実行結果が変わらない」とあります）。読点は ，（全角コンマ）が正式ですが、、 や , でも構いません。

  • 変数名は英字で始まる英数字と _ の並びです。小文字で始まる変数は通常の変数、大文字で始まる変数は配列、すべて大文字の変数は実行中に変化しない値（定数）を表すのが決まりです（シミュレーターはこの決まりを検査しません）。
  • 添字は 0 以上の整数です（問題によっては 1 以上の添字だけを使います）。二次元配列は Gyoretu[3，2] のように添字を ， で区切ります。
  • 文字列は 「見つかりました」 または "It was found." のように囲みます。

  • ， で区切ると複数の代入文を横に並べられます（左から順に実行）。
  • 配列は { } で値を並べて作れます。B ← A のように配列を代入すると、B の内容が A の内容に置き換わります（A の複製になります）。
  • Tokuten のすべての要素に 0 を代入する で配列のすべての要素を 0 にします。
  • kosu を 1 増やす は kosu ← kosu ＋ 1、saihu を syuppi 減らす は saihu ← saihu － syuppi と同じです。

8. 細かい動作の決まり

試験の説明資料で決められていない部分は、次のように動作します。

  • 割り算 ÷ と余り %：負の数では、商は小さい方に切り捨て、余りは割る数と同じ符号になります（-7 ÷ 2 → -4、-7 % 2 → 1）。正の数どうしなら普通の商と余りです。
  • 整数(x)：0 の方向へ切り捨てます（整数(-2.5) → -2）。
  • 小数：計算機の性質上の小さな誤差が出ないよう、表示は有効数字 12 桁に丸めます（0.1 + 0.2 → 0.3）。
  • 配列：まだない添字に代入すると配列が自動的に大きくなります。値を代入していない要素を読むとエラーになります（「すべての要素に〜を代入する」をした配列を除く）。存在しない配列の要素に代入すると、新しい配列が作られます。
  • 配列の代入：DNCL2 で B = A とすると、Python と同じように B と A は同じ配列を指します（B の要素を変えると A も変わります）。DNCL の B ← A は説明資料のとおり内容の置き換え（複製）です。
  • 表示する：値は間を空けずに連結します（例示の「カンマ区切りで文字列や数値を連結できる」による）。
  • 文字列：s[0] で 1 文字取り出せます。+ で連結でき、片方が数値でも連結になります。
  • 条件：比較の結果は「真」「偽」です。表示すると 真・偽 と出ます。
  • 大文字・小文字：変数名は大文字と小文字を区別します（kingaku と Kingaku は別の変数）。
  • 1 行に複数の文：, で区切って並べられるのは代入文だけです。
