# DNCL シミュレーター

大学入試で使われる手順記述言語を、ブラウザ上で実行・ステップ実行できるシミュレーターです。

- **DNCL2**：大学入学共通テスト「情報Ⅰ」用プログラム表記（`x = 3`、`表示する(x)`、字下げ・縦線でブロックを表す）
- **DNCL**：旧センター試験「情報関係基礎」の手順記述標準言語（`x ← 3`、`x を表示する`、`を実行する`・`を繰り返す` でブロックを閉じる）

## 使い方

ビルドは不要です。`index.html` をブラウザで開いてください（GitHub Pages などの静的ホスティングでも動きます）。

- `index.html` … シミュレーター本体
- `manual.html` … マニュアル（文法・組み込み関数・拡張機能・エラーの説明）

主な機能：

- DNCL2 / DNCL の切り替え、サンプルプログラム
- 実行・一時停止・ステップ実行（実行中の行を強調表示）、実行速度の変更
- 変数の値の表示（変わった変数を強調、関数内の局所変数も表示）
- 行番号つきエラーメッセージ（日本語）
- 試験問題の形式（行頭の `(01)` などの行番号、縦線 `│ ⎿`、全角記号）をそのまま入力可能
- 入力欄からの値の読み込み、関数定義などの練習用拡張

## 仕様について

「DNCL2」の正式な文法定義書は公開されていないため、大学入試センターの説明資料と過去の問題・試作問題の書き方をもとに文法を決めています。決められていない細かい動作（負の数の `÷` と `%` など）はマニュアルの「細かい動作の決まり」に記載しています。
